Informativa sulla Privacy

Titolare del trattamento: Luca Di Rienzo, info@rootsystem.it

Questa applicazione utilizza le API di Google (Gmail, Calendar, Drive) esclusivamente per fornire funzionalita' di automazione richieste dall'utente titolare dell'account Google collegato.

Dati trattati

  • Contenuti email (lettura, invio, organizzazione) tramite Gmail API
  • Eventi di calendario tramite Calendar API
  • File e documenti tramite Drive API, Docs API, Sheets API
  • Contatti (lettura) tramite Contacts API

Finalita'

I dati sono utilizzati esclusivamente per eseguire le automazioni richieste direttamente dall'utente titolare dell'account. Nessun dato e' condiviso con terze parti o utilizzato per scopi pubblicitari.

Conservazione

I dati sono trattati in tempo reale per l'esecuzione dei task richiesti e non vengono conservati permanentemente oltre quanto necessario all'operazione.

Diritti dell'utente

L'utente puo' revocare in qualsiasi momento l'accesso dell'applicazione tramite le impostazioni del proprio Account Google (myaccount.google.com/permissions).
